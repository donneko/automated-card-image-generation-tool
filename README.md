# 自動カード画像生成ツール

名簿のJSONデータを画像テンプレートに配置し、複数ページのPDFまたはページごとの画像として保存するPythonツールです。テンプレート画像の上に、設定したプラグインを使って文字などを描画します。

## 必要な環境

- Python 3.12以上
- Pillow
- `plugin.text` で使うフォントファイル（利用者が用意してください）

## セットアップと実行

リポジトリのルートディレクトリで仮想環境を作成し、有効化してから依存関係をインストールしてください。

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Windowsでは仮想環境の作成に `py -3.12 -m venv .venv` を使い、PowerShellの場合は `.venv\Scripts\Activate.ps1` を実行してください。

実行前に `config.json` の入力ファイルとフォントのパスを、自分のファイルに合わせてください。入力ファイルは設定された場所に置き、出力先ディレクトリも必要に応じて設定します。仮想環境を有効にした状態で、リポジトリのルートから次を実行してください。

macOSまたはLinuxでは、リポジトリのルートから次を実行してください。

```sh
./run.sh
```

スクリプトはリポジトリのルートを作業ディレクトリにして起動します。Windowsでは仮想環境を有効にしたPowerShellから、リポジトリのルートで `python -m src.main` を実行してください。仮想環境を有効にしていない場合は、`python3`（Windowsでは `python`）がPATH上にあり、PillowがそのPython環境にインストールされている必要があります。

## 入力データ

`config.json` の `input.template` はテンプレート画像のパス、`input.data` は名簿JSONのパスです。名簿JSONのトップレベルはオブジェクトの配列です。各オブジェクトには、描画対象となる値を文字列で含めます。現在の設定では、`name` と `name_roman` のキーを使用しています。各キーは `scripts` に登録されたプラグイン設定の `key` と一致させてください。

テンプレート画像のサイズやカードの配置に合わせて、カード設定の列数・行数、カード寸法、開始位置、横縦の間隔を調整してください。配置計算ではカード寸法と間隔を加算して次の位置を決めます。現在のカード番号計算は列数と行数が同じ設定を前提としています。

## 設定項目

- `input`: テンプレート画像と入力JSONのパス。
- `output`: 出力ディレクトリ、ファイル名、画像形式、1ファイルにまとめるかどうか、解像度。`save_one_page` は文字列の `True` または `False` で指定します。
- `cards`: 行列数、カード寸法、最初の位置、横縦の間隔。位置と寸法はテンプレート画像上のピクセル値です。
- `scripts`: データキーごとに使うプラグインのモジュール名と設定。`plugin.text` では文字の相対位置、フォントパス、色、サイズを指定します。フォントパスは実行時に参照できるファイルを指定してください。

入力データと生成物はGitの追跡対象外です。利用者自身の画像や名簿を公開リポジトリに追加しないでください。

## プラグイン

プラグインは `scripts` に指定したPythonモジュールです。モジュールには `setup(config)` と `print(draw, config, meta)` を定義します。`setup` は設定を受け取り、描画に使うフォントなどを準備して返します。`print` は Pillow の描画オブジェクト、準備済み設定、カード位置や現在の値を含むメタデータを受け取って描画します。

各プラグイン設定の `key` は入力データ内のキーに対応します。プラグインモジュールはPythonからインポート可能な場所に置き、`scripts` にモジュール名を指定してください。
